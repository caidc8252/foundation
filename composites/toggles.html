toggles · composite

Inline control-with-label wrappers: pairs a checkbox, radio, or switch primitive with an optional text label. This composite owns only the flex alignment layout; all control styling delegates to the underlying primitive.

1. Toggle Checkbox — multiple-select / boolean opt-in

.toggle-checkbox wrapping a .checkbox primitive + .label. Clicking the label text toggles the checkbox. Supports data-disabled="true".

Use .toggle-checkbox for multiple-select lists or boolean opt-in preferences. The <label> wrapper makes the text clickable to toggle the control.

2. Toggle Radio — single-select from a group

.toggle-radio wrapping a .radio inside a <fieldset> with <legend> for accessible group naming.

Shipping method

Wrap radio groups in <fieldset> + <legend> for an accessible group name. The name attribute links radios into a single-select group.

3. Toggle Switch — binary on/off preference

.toggle-switch wrapping a .switch primitive + .label. The switch uses data-checked and aria-checked attributes for checked state.

The .switch primitive uses data-checked / aria-checked="true" for the on state. The .switch__thumb slides inside the track. Disabled switches use aria-disabled="true".
