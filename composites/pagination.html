NUMBERED pagination · non-table contexts only

Page buttons reuse the button recipe: idle = ghost, current = soft primary-50/primary-700 fill + aria-current="page". Ellipsis collapses large page ranges. Do not use this variant in a list/table footer — it's for standalone search results, blog archives, etc.
