A compact before → after comparison: old struck through, arrow, new highlighted. Block layout for modals; inline layout for rows/cells.

1. Block — modify (both sides populated)

Used in confirm modals and audit logs. Old value struck + tertiary; new value in success-strong.

Member
AFTER
Admin

Role change: Member → Admin

2. Block — add (old side is em-dash)

Used when a new value is being created (no prior value to compare against).

BEFORE
—
AFTER
view_transactions

Permission added: — → view_transactions

3. Block — remove (new side is em-dash)

Used when a value is being removed (the new side shows the absence).

AFTER
—

IP address removed: 192.168.1.100 → —

4. Block — long values (word-break: break-all)

IDs, tokens, scopes, and addresses reflow inside their column without breaking mid-token.
