Detail header · reduced form (create / edit / wizard header)

The same composite carries the "with back" header on create / edit / wizard pages: the back button (exit without committing), the page title, and — on a single-step create / edit — a ghost Cancel + the primary commit (Cancel left, primary right; no logo, meta, chips, or tabs).
