theme-toggle · composite

An icon-only button that flips the app between light and dark. A ghost icon button with an 18px sun/moon glyph. Lives in the app header / chrome.

1. Theme toggle in an app header bar

The toggle sits alongside navigation controls and the user avatar. The ghost button has no chrome at rest — surface appears only on hover.

2. Moon vs Sun — which glyph the markup contains

The active glyph is determined by the resolved theme, not by CSS state. Moon (light mode) → tap to go dark. Sun (dark mode) → tap to go light.

3. Size reference — 36px (spacing-control-md) square

The toggle matches the default .btn--icon size (36px). One fixed size — no size prop.

Icon button
.btn--ghost.btn--icon
Theme toggle
.theme-toggle (quieter resting color)

The bare .btn--ghost rests at content-primary; .theme-toggle quiets the resting text to content-secondary. Hover lifts both back via the inherited ghost recipe (surface-hover bg + content-primary).

4. Focus-visible ring

Tab to the toggle below to see the shadow-focus ring. The native outline is removed in favor of the ring. Focus is never removed, only restyled.
