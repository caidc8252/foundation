Action patterns

The shared verb vocabulary — one card per action, showing its carrier and any surface it opens. See actions.md for the rules.

confirm-danger

Destructive confirm — delete / remove / revoke. Carrier opens a forced-action dialog.

or a danger text button — same dialog

Delete Acme Robotics?

This permanently removes the customer and its order history. This action cannot be undone.

secondary-action

A secondary tool action (e.g. Export). Lands in the list summary OR the page header — never both.

batch-action

Appears after multi-select; replaces the summary bar's idle actions. Destructive verbs route through confirm-danger.

transition

Status flip / approve–reject. Destructive directions use danger and a confirm; safe ones stay neutral.

Destructive directions (Suspend) open a confirm-danger AlertDialog. Safe directions (Activate) run directly — neutral tone, no confirm. Multiple statuses → use a dropdown-menu of status items instead.

picker

Relate / assign. Trigger opens a Combobox (inline) or a Modal list.
