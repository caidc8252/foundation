Action patterns

The shared verb vocabulary — one section per action, each in a believable slot with a live carrier that opens its real surface. See actions.md for the rules.

confirm-danger

Destructive confirm — delete / remove / revoke. The trigger carries danger tone (a ghost-danger icon or a danger text button) and opens an AlertDialog whose Confirm is danger too. Click either carrier to open the real dialog; it dismisses only via Cancel or Confirm.

secondary-action

A secondary tool action — Export, Import, Download, Refresh: a secondary button + a leading icon. It is not the page's primary CTA (that's reserved for Create / Save) and it does not confirm — it's read-only / reversible, so it just runs (spinner → done). It lands in exactly one place: the list summary bar or the page header — never both.

batch-action

Acts on a multi-selection. It lives in the summary bar and appears only after rows are selected — a selection count + a bulk button group that replaces the bar's idle actions (not a floating toolbar, not per-row buttons). Neutral verbs (Assign) run directly; destructive verbs (Delete) route through confirm-danger.

transition

Changes a record's status / lifecycle state — activate/suspend, approve/reject, publish/unpublish. Same record, but the direction decides the tone: destructive or service-interrupting directions (Suspend, Reject) use danger + a confirm; safe directions (Activate, Approve) stay neutral and run directly.

Status: Active

Suspend opens a confirm-danger AlertDialog; Activate runs directly — neutral tone, no confirm. Several target statuses → collapse them into a dropdown-menu of status items rather than a row of buttons.

picker

Relate / assign. A trigger opens a Combobox (inline) or a Modal list. Click to open; type to filter; pick to commit and close. No confirm; neutral tone.

copy

Copy an id / key to the clipboard — a ghost icon-sm + a copy glyph, landing in KV rows, detail meta, or section rows. It writes to the clipboard for real and flashes a check.

kebab (⋯) menu

One carrier per row — collapse a row's verbs to a ⋯ overflow past 2 frequent verbs. Click to open the real menu; it closes on select, outside-click, or Escape. Menu rows are .dropdown-menu__item (destructive → --destructive), never .btn.

Globex Inc.

Here the menu anchors under its trigger. In production it portals to the body: a kebab lives in a table row, inside .table-scroll, and an inline floating menu anchored inside a .table-scroll / .scroll-area / overflow:auto ancestor is clipped flat at the box's edge (principle 17). Lift it out of the overflow ancestor, or use a fixed surface.

confirm with input

When a confirm must capture context (a reject reason, a suspend note), an AlertDialog can't hold a field — so use a hardened Modal (closeOnOverlay + closeOnEscape off, no × close) that keeps the forced choice.

The modal dismisses only via Cancel or Reject — overlay-click and Escape are disabled, keeping the forced choice.

list-row quick-ops

Single-row verbs when a requirement calls for them — always-visible icon buttons (the list-page override): a ghost icon-sm for the action, ghost-danger icon-sm for a Delete that opens the confirm-danger dialog — not text buttons, not hover-reveal icons.

Delete opens the confirm-danger AlertDialog — the same surface as its full-size trigger. An abstract verb with no conventional glyph (Manage, Rotate key) routes into the ⋯ overflow instead.

Delete Acme Robotics?

This permanently removes the 3 selected customers and their order history. This action cannot be undone.
