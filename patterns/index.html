patterns · copyable examples

The L3 pattern contracts live in the *.md files beside this page — they are the single source of truth. Each card below opens an editable HTML companion: a ready-to-copy starter that renders the contract using foundation's reference layers. Copy one, then edit the markup.

Each example links the reference CSS — ../dist/tokens.inline.css → ../primitives/primitives.css → ../composites/composites.css (that load order matters) — so edits to tokens / primitives / composites flow straight through and nothing forks. To ship one as a self-contained artifact (CSP, no external fetch), inline those three blocks into a <style> instead, per the README. Each file is a ready-to-copy frameless page — the markup starts directly with <main class="app-frame__main">, no shell to strip.
