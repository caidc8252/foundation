Date-time picker · interactive

A fully functional date-time picker. Click the trigger to toggle the popover. Navigate months with the prev/next buttons, click a day to select it, set the time with the time input, and press OK to commit the combined selection. The clear button resets the trigger.

Date-time picker · range via two fields

The modern pattern for a date-time range: two independent date-time-pickers — a Start and an End field — instead of one oversized dual-calendar popover. Each field is the same component shown above; together they capture the range. Picking a start constrains the end calendar (earlier days are disabled), and the combined value updates live below.
