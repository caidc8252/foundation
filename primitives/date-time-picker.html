Date-time picker · default trigger

An idle trigger with placeholder text. Clicking opens the popover calendar. Root element is .date-picker wrapping an .date-trigger.

Date-time picker · with value

A trigger that shows a committed date-time and a clear button. The .date-trigger--clearable modifier makes room for the absolutely-positioned .date-trigger__clear.

Date-time picker · interactive

A fully functional date-time picker. Click the trigger to toggle the popover. Navigate months with the prev/next buttons, click a day to select it, set the time with the time input, and press OK to commit the combined selection. The clear button resets the trigger.
