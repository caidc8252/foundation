Date Range Picker · default trigger with value

The closed control uses .date-trigger with a calendar icon, .date-trigger__value showing from – to, and a clear button. Add .date-trigger--clearable when the value is present.

Date Range Picker · placeholder

When no range is selected, show placeholder text via .date-trigger__value--placeholder. The clear button is absent.

Date Range Picker · size variants

.date-trigger--sm, .date-trigger--md (default), and .date-trigger--lg.

Date Range Picker · disabled

Disabled trigger: cursor-not-allowed, opacity-50, clear button suppressed.

Date Range Picker · interactive

Click the trigger to open the popover. The popover contains a presets rail (left) and a two-month range calendar (right). Click a start date, then an end date to select the range. The trigger value updates with the chosen from – to range.
