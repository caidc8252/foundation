Basic labels

Standalone <label class="label"> elements above form controls. The label uses htmlFor to associate with the control id for native click-to-focus.

With required indicator

Append <span class="field__required" aria-hidden="true"> *</span> after the label text. The star is decorative — requiredness is communicated to AT via the control's own required attribute.

Label variants

The .label is an inline-flex container — it accommodates an inline icon or a small control beside the caption text via the gap-2 slot. Helper text (via .field__hint) lives below the control, not inside the label.

Disabled label

Add .label--disabled to the label to get cursor:not-allowed and opacity:0.5. In the artifact this is a static stand-in for the React group-disabled / peer-disabled variants. The control receives disabled on its own element.

Label with htmlFor

Click any label below to focus its paired input. The association is made via htmlFor="<input-id>", which the browser resolves natively — no JavaScript required.

Tip: labels without htmlFor are still valid — they pair via wrapping the control, but the explicit htmlFor pattern is preferred for flexible layout and assistive technology.
