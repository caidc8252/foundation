The four jobs — does this earn an icon?

An icon does exactly one of four jobs; if it isn't doing one, drop it (icon.md §The four jobs). Boundary: a compact status is a badge dot, not an icon — status becomes an icon only in a message container (the alert below).

1 · Action
names a verb — icon + text, or icon-only when the glyph is conventional and space is tight (with an aria-label + title)
2 · Status
Storage at 85%
severity in a message container — one glyph per severity (§Status glyphs). A status badge uses a dot, not this glyph.
3 · Identity
Customer Company Database
names what a thing is — one canonical glyph per entity type, reused everywhere it appears (§Identity & domain glyphs)
4 · Decoration
No results yet
an empty-state mark or feature bullet — larger, muted, never load-bearing
