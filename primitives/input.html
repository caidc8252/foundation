Input · sizes

Three size tiers: .input--sm (28px), .input--md (36px, default), and .input--lg (44px with larger text). The .input class alone defaults to md.

Input · types

Common type attribute values. All use the base .input class.

Input · states

Native HTML states. disabled dims at opacity-50; readonly swaps to surface-3; aria-invalid applies the error border and ring.

Input · validation

The orthogonal validation axis: .input--warn (warning-500 border) and .input--ok (success-500 border). These are independent of the size variant.

Input · filled variant

The .input--filled variant uses a tonal surface-3 background with a transparent border. The border appears only on focus. Ideal for dense toolbars and nested forms.

Input · with icon prefix

An inline SVG icon positioned inside the input using an absolute-positioned wrapper. The input gains additional left padding to accommodate the icon.
