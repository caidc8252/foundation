Date Picker · default md trigger

The closed state of the picker: .date-trigger with a leading calendar icon and placeholder text in .date-trigger__value--placeholder tone (content-tertiary).

Date Picker · with value

When a date is selected the value span uses content-primary and a trailing clear ✕ appears (.date-trigger__clear). The trigger gains .date-trigger--clearable for the right-padding that prevents text-overlap with the clear button.

Date Picker · size variants

Three sizes matching the .input size axis: .date-trigger--sm (control-sm, 28px, text-xs), .date-trigger--md (control-md, 36px, text-sm — default), .date-trigger--lg (control-lg, 44px, text-lg).

Date Picker · disabled

The disabled attribute or aria-disabled="true" sets cursor: not-allowed and opacity: 0.5. The clear button is suppressed.

Date Picker · invalid

Apply .date-trigger--invalid or aria-invalid="true" to show error styling: error-strong border + 2px error/20 ring. Same recipe as .input[aria-invalid="true"].

Date Picker · interactive

A fully functional date picker: click the trigger to open the calendar popover, use the prev/next buttons to navigate months, click a day to select it (the popover closes and the value updates), and use the clear button to reset. Today's date is outlined (.calendar__day--today) and the selected day is filled (.calendar__day--selected).
