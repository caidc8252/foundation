Tone — what does it mean? (semantic)

Colour is driven entirely by tone — there is no variant prop. Each tone maps to a semantic colour pair; default is neutral. Semantic tones carry status severity; neutral is for non-status labels (§10).

Shape — pill vs tag · is it a literal token?

A word read as language → pill (default, round, sans). A verbatim machine token you'd copy / compare char-by-char → .badge--tag (boxy radius-sm + font-mono). The box corners and the monospace are two cues for the same signal. Tone is a separate axis — a token can be neutral (an id) or carry a tone (an error code).

Leading adornment — dot / icon / none
