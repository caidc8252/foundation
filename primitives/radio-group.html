Vertical layout

A .radio group with three options stacked vertically. Wrap radios in a container using display:grid; gap:var(--space-2) and give them the same name for native single-select behavior.

Horizontal layout

Radios placed side-by-side using display:flex; flex-direction:row. The same single-select behavior applies via shared name.

With labels

Radios paired with standalone <label> elements using htmlFor / id. Each row uses a hidden span for the checked indicator, demonstrating the pattern used by base-ui's RadioGroupItem.

States

Default, checked, disabled, disabled+checked, and invalid (aria-invalid="true"). Disabled radios use opacity-50 and cursor:not-allowed. Invalid radios get a red border with a 2px error ring. The checked radio fills with primary-700 and shows a white dot.
