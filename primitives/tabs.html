Tabs · line variant

The .tabs__list--line variant: minimal style with a bottom hairline and an animated primary-700 underline on the active tab. Click a tab to switch panels.

Overview — This is the overview panel. It shows high-level information about the current item, including status, last updated, and key metrics.

Details — The details panel contains more granular information, such as configuration parameters, environment variables, and connection settings.

Settings — Manage preferences, permissions, and notification settings for this item.

Disabled tab — This panel belongs to a disabled tab.

Tabs · default (pill) variant

The .tabs__list--default variant: pill tabs inside a tinted tray. The active tab lifts with bg-surface-2 and shadow-1.

Billing — Manage your subscription plan, payment methods, and invoices.

Team — Invite team members, manage roles, and control access permissions.

Security — Configure password policies, two-factor authentication, and API keys.

Integrations — Connect external services and configure webhook endpoints.

Tabs · in a card

Tabs used inside a card layout for in-page section switching.

Project settings

General settings including project name, description, and default branch.

Environment variables and configuration for development, staging, and production.

Deployment settings including build commands, output directory, and auto-deploy branches.
