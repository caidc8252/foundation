Horizontal split (side by side)

Two panels side by side inside a .resizable-group (row flex). The vertical .resizable-handle is a 1px track with an invisible 4px hit strip (::after) for forgiving targeting. Drag the rule left or right.

Editor Drag the handle right to make this panel wider and give the editor more room. -
Preview Your changes appear here in real time as you edit. -

Vertical split (stacked)

Two panels stacked vertically. The group uses .resizable-group--vertical (column flex) and the handle adds .resizable-handle--horizontal so it renders as a full-width bar. Drag the rule up or down.

Output Console output and logs appear in this panel. -
Terminal A command-line interface for running scripts. -

Three panel layout

Three panels with two handles. Each .resizable-handle controls the panel to its left (previousElementSibling). The outermost panels can be resized independently; the center panel absorbs remaining space.

File tree Project files and folders. -
Editor The active file being edited. -
Outline Symbols and structure of the active file. -

With grip nub

Side-by-side panels with an explicit drag affordance: .resizable-handle__grip inside the handle. The nub is 8px × 24px (--space-2 × --space-6) with --color-line-strong fill. On a horizontal handle the nub rotates 90° to stay perpendicular to the drag axis.
