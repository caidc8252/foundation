Dropzone · resting

A dashed-border drop target: .dropzone with an upload icon, "Drop files here or click to browse" text, and a hidden <input type="file">.

Dropzone · drag active

Add .dropzone--drag when a file is dragged over the zone. Border shifts to --color-primary-500 and background tints to --color-primary-50.

Dropzone · disabled

Add .dropzone--disabled to prevent interaction. The zone dims (opacity: 0.6) and the cursor becomes not-allowed.

File list · file rows

After files are selected or dropped, they render as .file-row items inside a .file-list (<ul>). Each row carries an icon, name, size, optional progress bar, status indicator, and a remove button.
