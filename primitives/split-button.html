Split Button · variants

A default action fused with a menu trigger. Both segments share the same .btn--<variant>; the seam is a translucent divider on filled variants (primary / danger) and the trigger's own border on secondary. One primary Split Button per surface.

Split Button · sizes

Height-match the trigger to the segment: sm pairs with .btn--icon-sm, md with .btn--icon-lg.

Split Button · disabled

Disabling the control disables both segments.
