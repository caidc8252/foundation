Button · all variants (md)

Using .btn + .btn--<variant>. Six canonical variants: primary, secondary, ghost, danger, ghost-danger, link.

Button · all sizes

Using .btn--<size>. Sizes: xs (24px), sm (28px), md (36px, default), lg (44px), auto (content-driven).

Button · variant × size matrix

Each variant available in xs, sm, md, lg.

Button · icon-only

Using .btn--icon, .btn--icon-xs, .btn--icon-sm, .btn--icon-lg for square buttons with no label. All require aria-label for accessibility.

Button · disabled

All variants support a disabled state with cursor-not-allowed and opacity-50.

Button · with icon slots

Inline SVG icons as icon-left or icon-right slots. The button auto-sizes the icon to 14px and adds gap.

Button · loading

Click a button to enter the loading state — a spinner replaces iconLeft, the button disables for the duration, then reverts to idle.
