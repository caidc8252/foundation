Toggle Group · outline (default)

A Toggle Group is a set of two-state buttons managed together. Its select mode is the container's data-type (single / multiple) — independent of the visual variant below; for a lone on/off button use Toggle.
The .toggle-group--outline variant: connected segments sharing one outer border, separated by a right hairline divider (last item drops it). Shown single-select.

Toggle Group · segmented

The .toggle-group--segmented variant: a tinted track where the pressed item lifts into a pill (shadow-1). The same look works in either select mode — shown single-select (alignment) and multi-select (repeat days) — because the mode is the container's data-type, not the variant.

Toggle Group · cloud

The .toggle-group--cloud variant: standalone radius-full chips that wrap onto new lines. Each chip has a line-default border that lifts to primary-500 when pressed.
