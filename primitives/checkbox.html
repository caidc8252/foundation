Checkbox · basic states

A 16×16 square <input type="checkbox" class="checkbox">. All styling comes from primitives.css — no inline overrides. The check glyph (4×8 px) and minus glyph (8×2 px) are drawn by ::after pseudo-elements.

Checkbox · disabled

:disabled adds cursor-not-allowed + opacity-50.

Checkbox · interactive toggles

Click to toggle. The cycle checkbox (right) goes: unchecked → checked → indeterminate → unchecked.

Checkbox · "select all" pattern

The header checkbox uses .indeterminate = true (the native DOM property — matching :indeterminate in primitives.css) when some but not all items are selected. Clicking the header toggles all items.
